# 系统化调试

## 原则

- 先复现，再诊断，再修复。
- 不随机改代码。
- 不用症状修复掩盖根因。
- 每次失败都记录具体命令、输出和下一步变化。

## 步骤

1. 描述现象和影响范围。
2. 找到最小复现方式。
3. 收集证据：日志、测试输出、输入数据、环境信息。
4. 提出假设，并用最小实验验证。
5. 修复根因。
6. 添加或更新回归测试。
7. 运行验证命令。

## 三次失败规则

- 第一次失败：读错误，针对性修复。
- 第二次失败：换方法，不重复同一操作。
- 第三次失败：重新审视假设，必要时向用户说明阻塞。

## 常见硬件/链路场景

- 编译器或 SDK 缺失。
- 帧格式和 parser 不一致。
- SPI 半帧、粘帧、CRC 错。
- Qt/OpenGL 初始化顺序错误。
- 云端鉴权、CORS、请求体校验失败。
