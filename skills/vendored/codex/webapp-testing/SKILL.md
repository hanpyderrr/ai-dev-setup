# Web App Testing

## 适用

- 本地 FastAPI/React/Vite/静态 Web 页面。
- 需要截图、console 日志、网络请求检查。
- 验证按钮、表单、轮询、错误状态。

## 步骤

1. 启动本地服务。
2. 打开目标 URL。
3. 检查 console 和 network。
4. 验证主要用户路径。
5. 保存截图或记录关键输出。

## 报告

- 服务启动命令。
- 测试 URL。
- 浏览器检查结果。
- 失败日志。
