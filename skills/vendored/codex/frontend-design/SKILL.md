# 前端设计

## 原则

- 直接构建可用界面，不做空泛落地页。
- 根据项目场景设计：工程/数据工具应清晰、克制、可扫描。
- 文本不能重叠或溢出。
- 固定格式组件要有稳定尺寸。
- 避免无意义渐变、装饰球、泛 AI 风格。

## 对工程可视化项目的偏好

- 优先显示真实数据状态、错误、时间戳、连接状态。
- 操作按钮清晰，状态反馈明确。
- 支持空状态、加载状态、错误状态。
- 图表/画布旁保留关键数值摘要。

## 验证

- 运行构建或本地服务。
- 用浏览器检查桌面和窄屏视口。
- 查看 console 错误。
