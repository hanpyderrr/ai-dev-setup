# Codex Skills

These are Codex-oriented skills kept as part of this setup repository.

They can be restored into `~/.codex/skills` by the restore scripts after review.

Excluded on purpose:

- `codex-worker`: Claude-specific controller-to-Codex delegation flow.
- `codex-project-init`: Claude/Codex collaboration bootstrap that assumes Claude is controller.
- finance/trading skills unrelated to the current TOF project.

Recommended review order:

1. `planning-with-files-zh`
2. `systematic-debugging`
3. `test-driven-development`
4. `verification-before-completion`
5. `subagent-driven-development`
6. `webapp-testing`
